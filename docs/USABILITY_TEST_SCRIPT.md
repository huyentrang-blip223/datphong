# Usability Test Script Week 9

Use at least 5 real participants. Do not fabricate scores.

Tasks:
1. Find a homestay/room for a date range.
2. Create a booking with a guest account.
3. View a local product and recommendation.
4. Create a test product order.
5. Book a cultural experience.
6. As host, update availability and seasonal price.
7. As seller, create or edit a product.
8. As admin, view dashboard analytics.

After tasks, ask the 10 standard SUS questions scored 1-5 and record issues.
